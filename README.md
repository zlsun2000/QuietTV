# 静幕 QuietTV

打开电视，点一下，接着看上次没播完的剧——顺带换个干干净净、没有广告的桌面。

**[下载安装包](https://github.com/zlsun2000/QuietTV/releases/latest)** · [安装与恢复指南](docs/INSTALL.md)

![静幕实际运行界面](docs/images/quiettv-home.png)

*图片为早期版本在 Android TV 模拟器中的真实运行截图；新版设置菜单有所调整，你的桌面会显示自己安装的应用。*

## 能做什么？

- **继续观看或听歌**：把支持的应用最近没播完的内容放到桌面，点一下接着播，最多保留 8 条。Netflix、奇异果、SmartTube 等已有现成的适配文件（见下方「续播是怎么实现的」）。
- **输入源直达**：在支持的电视上，桌面直接进 HDMI 等输入源，不用层层翻系统设置。
- **整理应用**：收藏常用应用，隐藏不常用的图标，调整顺序或创建分类。
- **换个背景**：使用内置风景、自己的图片，或静音循环播放的视频。
- **查看时间和天气**：天气可以自己开启，并选择城市。
- **遥控器操作**：方向键移动，确认键打开，长按应用卡片进行整理。

静幕免费、开源，桌面本身不放广告。天气和播放记录默认关闭，按需要开启；记录只保存在电视上。

## 续播是怎么实现的？

每个视频/音乐应用"接着播"的接口都不一样，还会随版本变化。静幕不把这些逻辑写死在代码里，而是做成一份份 **JSON 适配文件**：

- 每份文件钉死目标应用的**包名、版本号范围和签名证书**——版本不对就不启用，宁可明确说"不支持"，也不假装能续播。
- 适配方式分三种：读取系统 Watch Next 记录、监听应用广播、读取应用的播放会话。
- 每条记录如实标注能力：能精确续播、能打开内容、或只能打开应用，不拿"打开应用"冒充"接着播"。

现成适配文件：[Netflix](docs/playback-rules/netflix-watch-next.json)、[TCL 渠道 B 站](docs/playback-rules/bilibili-tcl.json)；0.14.2 新增了奇异果、SmartTube 配置，可从[发布页](https://github.com/zlsun2000/QuietTV/releases/tag/v0.14.2)下载，导入后需手动启用。

想给自己常用的应用做一份？可以让 AI 逆向它的接口，按[适配指南](docs/PLAYBACK-RULES.md)生成配置文件。诚实提醒：适配只对验证过的版本负责，应用更新后可能失效。

## 怎么安装？

适用于**允许安装第三方应用的 Android 6.0 及以上电视或盒子**。不是 Android 系统的电视无法安装。

1. 打开[下载页面](https://github.com/zlsun2000/QuietTV/releases/latest)，下载文件名以 `.apk` 结尾的安装包。
2. 用 U 盘或你常用的文件传输方式，把安装包送到电视上并安装。
3. 从电视的应用列表打开"静幕"，按首次使用提示设置即可。

安装时不需要电脑调试，也不需要删除原来的桌面。如果电视允许更换默认桌面，可以把静幕设为默认；部分电视会限制这一操作或在重启后返回原桌面。有些电视会阻止安装从商店以外下载的应用，遇到提示时请看[安装帮助](docs/INSTALL.md#安装失败先区分原因)。

**已装旧版？** 0.13.0 至 0.14.1 的官方版本可直接安装 0.14.2，保留原设置。0.12.0 及更早版本不能直接升级；卸载会删除配置和记录，请先看[升级说明](docs/INSTALL.md#升级)。

想换回原桌面，可以在电视的默认桌面设置中重新选择它。详细步骤见[安装与恢复指南](docs/INSTALL.md)。

## 使用前知道这几件事

- **继续播放要看原应用是否支持。** 有些能接着播，有些只能打开内容或应用；不能保证每个视频、音乐应用都能精确续播。
- **输入源功能因电视而异。** 支持时可从桌面直接进入；其他电视可能需要到系统设置中切换。
- **在线海报需要你主动启用。** 启用带在线海报的适配后，图片服务会收到你的 IP 地址和海报请求，可能据此推测观看内容。详见[隐私说明](PRIVACY.md)。
- **天气需要联网。** 开启前会说明服务条件；当前免费天气服务适用于非商业使用。
- **视频背景取决于电视的播放能力。** 不支持的视频可换成图片背景。

静幕不提供影视或音乐内容，账号与会员仍由原应用管理。其他品牌的电视还需要更多实际使用反馈，详见[兼容说明](docs/COMPATIBILITY.md)。
