# 哪些电视和应用可以用

静幕适用于允许安装第三方应用的 Android 6.0 及以上电视或盒子。**能安装，不代表所有功能都能使用。** 不同电视对默认桌面、输入源和权限的限制不同，视频应用愿意提供的信息也不同。

## 先看你关心的功能

| 功能 | 目前可以期待什么 |
| --- | --- |
| 应用整理、时间、图片背景 | 属于基础桌面功能；其他品牌仍欢迎反馈，不能保证全部电视都适用 |
| 视频背景 | 支持静音循环；能否播放某个文件取决于电视。0.14.1 修复了部分电视播完一遍后停止的问题 |
| 按 Home 回到静幕 | 取决于电视是否允许更换默认桌面；部分 Google TV 可尝试“Home 键修复”，仍需实际确认 |
| 完全关机后进入静幕 | 取决于厂商开机设置，不能保证；请保留原厂桌面 |
| HDMI、TV、AV 输入源 | 电视提供可用入口时显示；接口、接入状态或设备名可能无法读取，未知时不会凭空补出 |
| 天气 | 需联网、主动开启并手动选城市，当前免费服务仅供非商业使用 |

安装失败和恢复原桌面的步骤见 [使用帮助](INSTALL.md)。

## 继续播放能支持哪些应用

所有来源加起来最多保留 8 条。应用没有提供封面、集数或进度时，静幕无法补齐；显示“打开应用”也不表示能自动接着播放。

| 应用 | 已知情况 |
| --- | --- |
| Netflix | 在一台 Android 12 电视、Netflix 13.2.1（内部版本 27207）确认过：导入对应适配文件并授权后，能显示两条记录，用户确认点击可以续播、海报可显示。其他版本、资料切换和完全重启后的表现还没确认 |
| B 站 | 早期特定电视渠道版本曾成功记录和续播；当前使用的 1.7.7 尚未成功适配，不能因为装了适配文件就认为可用 |
| 奇异果 | 特定 TCL 渠道版本有记录和打开内容的适配，尚未确认所有情况下能准确回到上次进度 |
| Apple Music 和其他音乐应用 | 可尝试读取应用提供的当前播放信息。原内容仍在播放应用中时可能恢复播放；公开版不包含早期个人版的专用音乐续播功能 |
| Disney+ 及其他应用 | 可以尝试自动识别，但具体版本尚未实测。不能保证标题、集数、封面或精确续播 |

部分适配需要电视系统保存的“继续观看”记录和额外授权；有些电视没有这个功能。静幕不会导入各平台账号的全部历史，也不会绕过会员、播放广告或清晰度限制。

## 实际测过哪些环境

- **雷鸟 50F295C-JN，Android 9**：早期个人版使用中验证过应用整理、默认桌面、动态背景等。这些结果不能直接代表当前公开版的全部功能。
- **一台 TCL Android 9 电视**：公开预览包确认过从奇异果返回后背景恢复。另一个个人构建中的相同循环实现连续播放过 15 轮；0.14.1 公开安装包没有在该机重新实测。该设备也发现过额外安装限制。
- **一台 TCL Android 12 电视**：测试版确认过部分输入源排序、游戏机开机/待机显示，以及上面说明的 Netflix 续播。空接口状态等问题仍有待确认。
- **电脑中的 Android TV 6、9、11 测试环境**：检查过安装、升级和相关桌面功能；无法代替真实电视的 HDMI、开机限制和视频播放能力测试。

其他品牌和新系统仍需要更多反馈。想反馈问题，提供电视型号、静幕版本、发生的问题和操作步骤即可；不知道系统版本或分辨率可以留空。

维护者可查阅 [完整检查记录](COMPATIBILITY-DETAILS.md)，其中按日期保留测试版本、方法、结果和限制。
