# 安装、升级与使用帮助

**中文** · [English](INSTALL.en.md)

适用于**允许安装第三方应用的 Android 6.0 及以上电视或盒子**。不是 Android 系统的电视无法安装。静幕目前不在 Google Play 商店提供下载。

## 不使用电脑

1. 打开[官方下载页](https://github.com/zlsun2000/QuietTV/releases/latest)，下载文件名以 `.apk` 结尾的安装包。不要下载名为 **Source code** 的文件，那是给开发者的源码。
2. 用 U 盘或文件传输工具送到电视上，再用电视的文件管理器打开安装包。
3. 如果提示不允许安装，按提示允许你正在使用的文件管理器安装应用。不同电视的菜单名字可能不同。
4. 安装后，在应用列表打开“静幕”。遥控器方向键选择、确认键打开，长按应用卡片进行整理。
5. 按首次使用提示选择默认桌面。如果按 Home 键出现选择窗口，选择静幕，再选“始终”。有些电视需要到系统的“默认应用 / 主屏幕”中选择，也有电视不提供这个选项。

整理应用、查看时间和使用已导入的背景都可以不联网。天气和播放记录默认关闭，需要时再到“桌面设置”开启。

**安装成功、按 Home 返回静幕、重启后自动进入静幕，需要分别确认。** 有些电视仍会在开机时打开原厂桌面。请保留原桌面，不要为了切换桌面而删除或停用它。

## 升级

- **0.13.0 至 0.14.1 的官方版本升级到 0.14.2**：直接打开新版安装包安装，不用先卸载，收藏、背景、设置和记录会保留。
- **0.12.0 及更早版本**：新版安装包的身份凭证已更换，无法直接装在旧版上。需要卸载再装，**卸载会删除静幕里的配置、收藏、背景和播放记录**。先确认能接受这些数据丢失，再操作。
- **自己修改或从其他地方下载的版本**：可能无法直接安装官方新版。遇到“应用未安装”时先核对来源，不要急着卸载已有数据的版本。

0.13.0 之后的官方版本沿用同一份发布身份凭证，正常升级可直接安装新版。系统通常不允许装回更旧的版本。升级后若 Home 键返回了原桌面，可以重新选择默认桌面。

旧个人版的 Apple Music 专用续播和自动识别城市不在公开版中。天气需要自己选择城市，音乐续播取决于音乐应用是否提供相应信息。

## 安装失败先区分原因

先记下屏幕上的原话，再按下面的情况处理。允许“未知来源”后仍失败，也可能是电视厂商另外限制了第三方应用或桌面，不一定是安装包坏了。

| 电视上的提示或现象 | 可以先做什么 |
| --- | --- |
| 不允许这个来源安装应用 | 给实际打开安装包的文件管理器授权，再试一次 |
| 显示 Google Play Protect / Play 保护机制 | 这是 Google 的应用安全检查；先查看提示和扫描结果，可参考 [Google 官方帮助](https://support.google.com/googleplay/answer/2812853?hl=zh-Hans) |
| 已允许安装，仍提示失败 | 尝试电视原厂文件管理器的安装入口；若仍失败，提供电视型号、静幕版本、安装方式和提示文字 |
| 提示与已安装版本冲突 | 可能是旧版和新版来源不同；先看上面的升级说明，卸载会丢数据 |
| 提示版本较旧或系统不支持 | 核对下载的版本及电视 Android 版本，不要反复安装同一个包 |

一台 TCL 电视已确认存在额外安装限制，其他型号的情况可能不同。**允许安装第三方应用，并不代表一定允许安装第三方桌面。** 这类限制无法通过静幕里的设置解除。

如果需要用电脑进一步排查，见 [错误码、厂商调查与电脑安装方法](INSTALL-ADVANCED.md)。其中有针对已确认问题的单次安装选项，会在结束后恢复原设置；它不是所有电视通用的解决办法。不要为安装静幕而关闭全部安全检查或删除原厂安装器。

反馈时只需提供型号、版本和提示文字；截图先遮住账号、网络地址和私人内容，不要提交完整的私人日志。

## Google TV 的 Home 键

Home 键就是遥控器上返回桌面的按键。有些 Google TV 即使选择了静幕作为默认桌面，按这个键仍会回到原厂桌面。可以尝试可选的“Home 键修复”：

1. 进入“桌面设置 → 系统与桌面 → Home 键设置”，打开“Home 键修复”。
2. 按提示进入系统“无障碍”设置，开启“静幕 · Home 键修复”。
3. 返回后按一次 Home 键，确认是否回到静幕。只看到开关已打开，还不能说明电视已经允许它生效。

此功能默认关闭，只处理 Home 键，不读取画面内容。关闭静幕里的开关，或在系统无障碍设置中停用该服务，即可恢复原来的按键行为。部分电视会限制这类权限，也可能影响长按 Home 的快捷功能；不适用时关闭即可。

目前还没有在 Google TV 实机确认这项功能。它与“设为默认桌面”是两件事，也不保证完全关机后自动进入静幕。

## 背景

进入“桌面设置 → 背景与外观 → 自定义背景 → 从系统文件选择器导入”，选择自己的图片或视频。

常见图片和视频文件都可以尝试，包括 JPEG、PNG 和 MP4。图片最大 50 MB，视频最大 400 MB。选中的文件会复制到静幕里，之后可以拔掉 U 盘。想使用视频背景，建议先试一段体积较小的 1080p MP4；电视不能播放时会显示内置风景。

电视没有文件选择器时，可尝试“U 盘 / 旧系统文件浏览”，按提示允许读取文件。拒绝该权限后仍可使用内置背景和已经导入的背景。更多格式和排查记录见 [兼容技术资料](COMPATIBILITY-DETAILS.md)。

## 继续播放

1. 进入“桌面设置 → 继续播放”，开启“显示播放记录”。
2. 在“记录来源与权限”中开启“自动识别媒体播放”，再进入“媒体访问权限”，按系统提示允许静幕访问通知。
3. 到原来的视频或音乐应用正常播放一次，再返回静幕查看。可以在应用名单中关闭不想记录的应用。

系统把这项权限叫作“通知访问”，静幕只使用播放应用提供的标题、封面、进度等播放信息，**不读取通知正文**。不愿授权也可以正常使用基础桌面。有些电视不提供授权入口，或者需要先在应用信息中选择“允许受限设置”。

最多保留 **8 条记录**。应用没有提供封面、集数或进度时，静幕无法自动补齐。卡片显示“打开应用”时，只会进入应用；显示“恢复当前播放”时，需要原来的内容仍可控制。能否从上次位置继续，由原应用决定。

部分应用还可导入额外的适配文件：在“高级设置 → 应用适配规则 → 导入 JSON 规则”选择文件，查看它适用的应用版本和说明，再手动启用。这里的 JSON 就是适配文件的格式，不需要自己编程。Netflix 等适配可能另需按提示允许读取“电视节目表”；电视不提供这项功能时，导入文件也无法补齐。

Netflix 仅在特定版本和设备上确认过续播；当前 B 站 1.7.7 尚未成功适配，Disney+ 尚未实测。使用范围见 [兼容说明](COMPATIBILITY.md)，制作适配文件见 [开发者指南](PLAYBACK-RULES.md)。

## 天气

进入“桌面设置 → 天气”，阅读服务说明后开启，搜索并选择自己的城市。静幕不会自动根据网络地址定位城市。天气需要联网，当前免费服务仅供非商业使用；不想使用时随时关闭。

## 恢复原桌面

到电视系统的“默认应用 / 主屏幕”设置，重新选择原桌面。静幕里的“打开其他桌面”只打开一次，不会更换默认值。

如果开启过“Home 键修复”，也要关闭这个开关或停用对应的无障碍服务。确认按 Home 能回到原桌面后，可以保留或卸载静幕。卸载会删除静幕自己的配置和背景，**通常不需要恢复出厂设置**。

静幕不删除原厂应用、不修改系统分区，也不调整开机广告或屏保。

## 使用 ADB 的高级安装

熟悉电脑命令、需要进一步排查的用户，请看 [电脑安装与错误码说明](INSTALL-ADVANCED.md#使用-adb-的高级安装)。普通安装不需要完成这些步骤。
