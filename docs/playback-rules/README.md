# 奇异果和 SmartTube 续播配置

这两份文件可以让符合条件的应用把播放记录放到静幕桌面，方便下次接着看。**先核对应用版本，再导入；不是给所有爱奇艺或 YouTube 客户端通用的文件。**

| 文件 | 适用应用 | 已经测到的效果 |
| --- | --- | --- |
| [奇异果配置](qiyiguo-tcl-16.9.json) | TCL 渠道奇异果 16.9.0.221250 | 含广告内容从桌面进入后，仍能更新集数与进度；续播位置由爱奇艺自己的历史决定。 |
| [SmartTube 配置](smarttube-32.56-session.json) | SmartTube 32.56，包名 `org.smarttube.stable` | 关闭客户端后，从桌面卡片重新打开，约从原来的 2:22 自动接着播放。 |

实测设备是雷鸟 50F295C-JN、Android 9，使用个人测试版静幕。公开分支另有配置导入和参数检查；**尚未在这台电视上重新安装公开 APK 验收，也没有验证所有电视、账号和内容。**

## 下载前看这里

- **SmartTube 配置可用于已有的 0.14.0 / 0.14.1 导入功能。** 但这两个公开安装包没有在上述电视上重新验收。
- **奇异果配置需要本次贡献新增的“按应用进度续播”支持。** 0.14.1 及更早的公开安装包会拒绝导入。提交源码不等于已经发布新安装包；请等后续发布说明明确支持后再用，或由开发者自行构建本分支。
- **旧 SmartYouTube 6.17.739 不适用。** 文件不能让它产生原本没有提供的播放记录。这里不附带客户端安装包，也不要求删除原来的应用。
- 两份公开文件都不下载网上封面。有些记录会显示应用提供的图片，有些显示应用图标。个人测试版中的联网封面扩展没有随本次贡献发布，续播参数相同。

## 怎么使用

1. 打开上表中的文件，在 GitHub 文件页下载 JSON，再通过 U 盘或自己的文件传输方式送到电视上。
2. 打开「桌面设置 → 继续播放」，开启播放记录与“其他应用自动识别”。按提示允许访问播放信息；不需要把账号或密码交给静幕。
3. 进入「高级设置 → 应用适配规则 → 导入 JSON 规则」，选择文件。电视没有文件选择页面时，需要先安装文件管理器。
4. 核对应用名称、版本和测试说明，保存后手动启用。如果提示同一应用有重叠配置，先停用旧配置。
5. 回到原应用正常播放一次，再返回静幕。配置不会导入账号过去的全部观看历史。

SmartTube 还需要允许它发布播放通知；没有播放信息时，静幕无法记录进度。版本不匹配时，不要随意放宽文件里的限制，应为实际版本重新核对接口。

## 爱奇艺的续播位置为什么由应用决定

本机含广告内容通过原来的详情入口播放后，曾出现只剩“打开应用”卡片的问题。现在使用爱奇艺自己的完整播放入口，让它读取自身历史，再向桌面发送更新后的记录。

**这能恢复应用自己记住的进度，但不能保证点较旧集数卡片就一定回到那一集。** 原应用可能选择该剧当前正在看的集数。想明确选择早前某一集时，请到爱奇艺内选择。

## 想停用或恢复

在「应用适配规则」中停用即可，已有记录不会因此删除。更新同一配置时保留一份旧配置，可在详情中回退；回退后仍要自己启用。静幕最多保存 8 条播放记录。

这些文件只描述应用提供的播放信息和入口，不修改播放器，也不改变会员、广告或内容授权。遇到失败时，告诉维护者应用版本、电视型号和操作步骤即可；不要公开账号、完整播放日志或私人观看记录。

想给自己的应用制作配置，可看[这次的开发过程和 AI 排查方法](../QIYI-SMARTTUBE-DEVELOPMENT.md)。
