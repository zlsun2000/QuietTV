# 1.0.2 候选版验证记录

本记录对应 1.0.2 / versionCode 43。4K 图层研究的原始基线见 [4K 渲染研究](4K-RENDERING-RESEARCH.md)。

## 改动和可测目标

| 项目 | 1.0.1 基线 | 候选版目标 |
| --- | --- | --- |
| 上下切换 | 焦点卡片在行间有短距离过渡，旧焦点回缩动画为 180 ms。 | 旧焦点的回缩缩短到 90 ms，减少连续操作时重叠的动画；保留选中卡片的动画、整行裁切和低内存简化路径。通过帧耗时对比，不将动画时间变化直接等同于性能改善。 |
| 4K | API 34 TV 模拟器和此前核对的 TCL Android 12 电视均报告物理 4K、普通窗口 1080p。原界面及给定壁纸的窗口截图为 1920×1080。 | 在「控制中心 → 主页布局」提供默认关闭的「4K 高清桌面」。设备条件允许时申请最高 4K 的桌面和应用自有设置图层，并按相应尺寸加载壁纸；条件不满足或图层失败时回到普通显示。 |
| 主页提示 | 左下角常驻遥控操作文字。 | 移除主页常驻提示，在首次使用帮助中说明方向键、确认、长按与移动；已有用户可从「系统与桌面 → 使用帮助」查看。 |

源码保留原有播放规则、签名验证与续播路由。4K 开关不重置收藏、分类、壁纸、播放记录或已选权限。图片资源本身、系统页面以及电视厂商的最终画面合成仍会影响可见清晰度；应用申请到 4K 缓冲区并不单独证明电视最终输出保留了全部细节。为了控制内存占用，独立图层最大按 3840×2160 的像素预算申请，系统原生提供更大窗口时不额外降低系统窗口尺寸。

## 编译与模拟器

- 构建通过，核心检查 406 项通过。APK 使用临时测试密钥运行隔离模拟器；提供给维护者的测试包单独使用与电视现有版本相同的签名。
- 发布检查发现电视测试包的两份现有内置续播规则使用了不同的换行符。发布候选重新使用仓库中的原文件；逐项核对 APK 后，除这两份规则的换行符外，执行代码和其他非签名文件与电视测试包逐字节一致，规则内容也一致。
- API 34 TV、SwiftShader 软件渲染、物理显示模式 3840×2160 / 普通窗口 1920×1080：完整候选在 4K 图层开启时通过 249 项显示检查，包括方向键、整行裁切、整理、焦点恢复和合成视频壁纸循环。该轮使用最终尺寸边界修正前的候选构建；修正后的最终候选另通过 9 项 4K 开关及图层检查和 8 项焦点／提示检查。
- 最终候选的 9 项检查覆盖默认关闭、开启、实际图层缓冲区尺寸、合成壁纸、控制中心和设置图层、焦点、关闭恢复及模拟严重内存压力回退。`PixelCopy` 在桌面图层取得 3840×2160 缓冲；控制中心的独立图层也大于其普通窗口。模拟器系统合成截图仍是 1920×1080，这不是最终 4K 输出证明。
- 使用维护者提供的 4095×2160 图片，在此前同一路径的候选上实际检查解码位图为 4095×2160，桌面源图层为 3840×2160；图片和截图仅保存在本地忽略目录，未提交到仓库。
- API 34 全新安装 31 项通过。从 1.0.1 / code 42 到 1.0.2 / code 43 的覆盖升级 13 项通过，检查收藏、隐藏项、分类顺序、栏目开关、壁纸文件、播放记录、已授予的电视列表权限及未授予的通知权限。旧用户不重新出现首次使用帮助，4K 默认为关闭。
- API 28（Android 9）电视模拟器：全新安装 31 项、非 4K 输出回退 2 项、设置导航 166 项和焦点／提示 8 项通过。模拟器不代表 TCL 固件或实机 4K 表现。
- API 23（Android 6）电视模拟器：全新安装 30 项、非 4K 输出回退 2 项和焦点／提示 8 项通过；该系统上没有执行默认桌面选择的 shell 命令。
- 在另一个较小内存的 API 34 模拟器上，非 4K 输出回退 2 项通过。该模拟器没有报告 `isLowRamDevice`；在隔离源码副本中强制应用走低内存分支后，4K 禁用检查 3 项和焦点检查 8 项通过。这是模拟分支，不是真实低内存设备或完整内存压力验证。

## 上下切换的帧耗时对比

在同一 API 34 软件模拟器上交替运行基线和候选：42 个合成应用、3 个常用、1 条合成续播记录，每轮同样 54 次方向键输入、间隔 200 ms，4K 关闭。基线仅为便于覆盖安装而把测试包的 versionCode 提高到 43，界面代码为 1.0.1；候选移除了底部提示，因此可用视口高度略有变化。各轮焦点路径一致。

| 轮次 | 1.0.1 基线：系统标记卡顿帧 / P50 / P95 | 1.0.2 候选：系统标记卡顿帧 / P50 / P95 |
| --- | --- | --- |
| 1 | 246/293（83.96%）/ 77 / 117 ms | 204/320（63.75%）/ 48 / 113 ms |
| 2 | 225/378（59.52%）/ 48 / 109 ms | 217/236（91.95%）/ 97 / 133 ms |
| 3 | 244/266（91.73%）/ 93 / 129 ms | 219/235（93.19%）/ 97 / 129 ms |

各轮差异很大，不能据此证明掉帧改善，也不能排除候选存在回退。两端 PSS 只在每轮前后各采样一次，约 43.5–58.2 MiB，未覆盖独立图层和 GPU 合成的全部内存。原始日志在本机忽略目录 `emulator-local/v102-work-20261116/`，不提交。需要在同一真实电视、相同内容和操作下继续比较，并由使用者评价手感。
