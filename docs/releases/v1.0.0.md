静幕 1.0.0 把主页布局集中到控制中心，方便用遥控器调整想看到的内容。

## 这次更新了什么

- 常用应用和有内容的继续播放默认并排。在「控制中心 → 主页布局」开启「分行显示」后，可在「设置 → 桌面设置 → 应用与分类 → 分类管理」分别调整两行的顺序。
- 在「主页布局」可分别关闭常用应用、继续播放和输入源。关闭继续播放会隐藏整行并暂停记录，已存记录会保留。隐藏主页输入源后，仍可在控制中心切换信号源。
- 续播卡片把来源、已有进度和可执行的操作分开显示。没有封面时使用本地占位。卡片显示「打开应用」时，确认键会进入对应的应用。
- 控制中心左栏选分类，右栏直接操作。桌面右上角显示网络状态，时钟和文字在壁纸上使用局部阴影。长按应用卡片可打开整理菜单。

## 下载和安装

下载本页的 **QuietTV-v1.0.0.apk**，用 U 盘或文件传输工具送到电视上安装，再从应用列表打开静幕。其余附件用于核对文件。

适用于允许安装第三方应用的 **Android 6.0 及以上电视或盒子**。天气和继续播放默认关闭，需要时可以在静幕里开启。

## 升级前看这里

- **官方 0.13.0 至 0.14.2** 可以直接安装新版，保留收藏、背景、设置和播放记录。
- **0.12.0 及更早版本**需要先看升级说明。卸载旧版会删除静幕中的收藏、背景、设置和播放记录。[升级说明](https://github.com/zlsun2000/QuietTV/blob/v1.0.0/docs/INSTALL.md#升级)

## 安装失败或功能用不了怎么办

部分电视会限制安装商店以外的应用，或不允许更换默认桌面。安装、按 Home 返回静幕和开机进入静幕需要分别确认。遇到问题先看安装帮助并保留原厂桌面。[安装帮助](https://github.com/zlsun2000/QuietTV/blob/v1.0.0/docs/INSTALL.md#安装失败先区分原因)

已用本次安装包在 TCL Android 12 上验证覆盖升级和遥控器操作。[验收记录](https://github.com/zlsun2000/QuietTV/blob/v1.0.0/docs/UI-UX-VALIDATION.md)
