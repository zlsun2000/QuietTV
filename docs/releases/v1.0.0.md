# 静幕 1.0.0 发布说明草稿

> **尚未发布，也没有可下载的 1.0.0 安装包。** 本文记录计划内容，需在最终构建、签名、设备检查和发布后重新核对；不能直接作为已发布版本的说明。

静幕 1.0.0 计划让桌面设置、应用整理和继续播放更容易使用，同时保留原来的安静桌面。

## 计划中的更新

- 默认仍将常用应用和继续播放并排显示。可在“控制中心 → 桌面设置 → 主页布局”开启“分行显示”，分别调整顺序；也可关闭“显示常用应用”。
- 继续播放卡片区分来源、已有进度和实际操作；没有封面时使用本地占位。应用提供什么入口，卡片就说明什么操作，不保证所有内容都能从上次位置继续。
- 控制中心集中显示时间、网络状态和常用入口；桌面设置保留分类和逐级返回。应用整理、空状态和背景上的文字可读性也在改进。

具体行为和菜单名称以最终验收的安装包为准。滑动流畅度仍在排查，当前不能宣称已修复。

## 下载和安装

目前没有正式安装包。发布时将核对安装包名称、文件校验值和签名，并在发布页提供下载；不要把个人测试签名的安装包当作官方更新。

计划支持允许安装第三方应用的 Android 6.0 及以上电视或盒子；具体兼容情况以实际验收和[兼容说明](../COMPATIBILITY.md)为准。

## 升级前看这里

- 计划沿用 0.13.0 起的官方签名。只有正式包的签名核对一致、且升级验证通过后，才能确认 0.13.0 至 0.14.2 官方版本是否可直接安装并保留设置、收藏、背景和记录；**目前尚未完成确认**。
- 0.12.0 及更早版本涉及签名更换。卸载会删除静幕中的设置、收藏、背景和播放记录；先看[升级说明](../INSTALL.md#升级)。自行修改或其他来源的版本也可能不能直接更新，不要为了处理安装冲突直接卸载旧版。

## 安装失败或功能用不了怎么办

部分电视会限制安装商店以外的应用，或不允许更换默认桌面。安装成功、按 Home 返回静幕、开机进入静幕需要分别确认；保留原厂桌面。遇到问题先看[安装帮助](../INSTALL.md#安装失败先区分原因)。

本次正式包尚未在 TCL Android 9 和 Google TV Streamer 真机验收；真实低内存设备路径和从旧官方安装包直接升级也尚待检查。电视模拟器不能代表所有电视。天气与播放记录仍需自行开启，续播结果取决于应用和设备实际提供的能力。
