# 0.12.0 发布前来源与风险审查

日期：2026-10-11。对象为拟公开源码、可达 Git 历史和由该源码生成的 APK。本文件记录源码审查与发布决策，不是律师法律意见，不宣称消除所有风险。范围为免费、无广告的基础桌面及用户明确开启的增强功能；个人音乐客户端与历史工具不在范围内。

## 法律依据与判断边界

[著作权法](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html) 保护软件等作品，第四十九条涉及技术保护措施；现行 [反不正当竞争法](https://ipc.court.gov.cn/zh-cn/news/view-4440.html) 第十三条涉及网络服务正常运行和数据获取。据此，本项目排除 DRM/广告/付费限制绕过与来源未明内容，以减少对应争议；此判断不保证所有互操作接口在所有场景都合法。

B 站/奇异果本地互操作为项目独立实现，只使用应用向系统发送的信息并校验固定入口，不读取私有数据库、账号凭据、通知正文或播放流，不要求修改媒体应用。接口长期可用性、个别版本条款及用户地区仍需具体核实，不能宣称官方支持。标准媒体会话按 [Android 官方接口](https://developer.android.com/reference/android/media/session/MediaSessionManager) 实现。

本次未覆盖专利自由实施、全球商标/外观相似性、所有海外法律或商业运营合规，也未判定 AI 图像在各地的著作权归属。商业化、加入云服务/统计、采用第三方代码、分发音乐客户端或重新引入网络资料查询时，须另做审查，不能继承本次结论。

## 发布闸门与留档

发布前运行 `python tools/check-release.py --apk QuietTV.apk`，检查公共路径、可达历史、敏感模式、排除接口与最终包内容；自动扫描不能替代人工来源核对。构建、核心检查和模拟器检查按 RELEASING.md 记录；Release 元数据须含源码 commit、APK SHA-256、公开签名证书、审查文档和验证边界。

发现来源未明、许可冲突或凭据残留时停止该内容发布，先移除并重建/审查。来源明确的基础代码可独立发布。个人备份、旧音乐补丁和账号工具不发布；将来分发时须单独审查 GPL、服务条款和技术保护措施。
